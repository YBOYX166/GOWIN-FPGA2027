## 2. 帧格式

```
字节   0      1        2     3      4 ... 3+LEN     4+LEN
     [0x55] [帧头高] [ID] [LEN] [DATA ...]        [CHECKSUM]
```

| 字段 | 说明 |
|---|---|
| 字节 0 | 固定 `0x55` |
| 字节 1 | `0x55` = **主动上传帧**；`0xAF` = **应答帧** |
| 字节 2 | 帧 ID（见 §3 / §5）|
| 字节 3 | 数据长度 LEN（0 ~ 28）|
| DATA | LEN 个字节，数值一律**小端** |
| CHECKSUM | 从字节 0 累加到最后一个 DATA 字节，**取低 8 位** |

**校验和计算：**

```python
checksum = sum(frame[0 : 4 + LEN]) & 0xFF
```

**举例**（姿态角帧，roll=90°, pitch=-45°, yaw=179°）：

```
55 55 01 06 00 40 00 E0 4A 7F 9A
│  │  │  │  └────┬────┘ └──┬──┘ └─ 校验和
│  │  │  │    roll/pitch/yaw（小端 int16）
│  │  │  └─ LEN = 6
│  │  └─ ID = 0x01（姿态角）
│  └─ 0x55 = 主动上传
└─ 固定帧头
```

逐字段拆开看：

| 角度 | 计算 | int16（十进制）| 小端字节 |
|---|---|---:|---|
| roll = 90° | `90/180 × 32768` | 16384 | `00 40` |
| pitch = −45° | `−45/180 × 32768` | −8192 | `00 E0` |
| yaw = 179° | `179/180 × 32768` | 32586 ⚠️ | `4A 7F` |

> ⚠️ **两个容易踩的点**：
> 1. **180° 存不进 int16**（`180/180×32768 = 32768` 超了），最大只能表示
>    `32767/32768×180 = 179.9945°`。所以别指望能精确读到 180.000°。
> 2. 上面的 179° 用的是**四舍五入**（32586）。如果代码写 `int(...)` 截断，
>    会得到 32585（字节 `49 7F`）—— **差 1 个 LSB 是正常的**，不是协议问题。
>
> 校验和核对：`55+55+01+06+00+40+00+E0+4A+7F = 0x29A`，取低 8 位 = **`0x9A`** ✅

**帧同步**：靠 `0x55` 找起点，之后每一段都严格校验；任何一步不合法就退回
"等 0x55"。所以被截断、串扰、半帧都不会被误认，最坏只是丢一帧。

## 3. 主动上传帧（帧头高 = 0x55）

模块按设定速率主动推送，帧 ID 表示内容：

| ID | 内容 | 常量名 |
|---:|---|---|
| `0x01` | 姿态角 | `UP_ATTITUDE` |
| `0x02` | 四元数 | `UP_QUAT` |
| `0x03` | 加速度计 + 陀螺仪 | `UP_GYRO_ACCE` |
| `0x04` | 磁力计 | `UP_MAG` |
| `0x05` | 气压计 | `UP_BARO` |
| `0x06` | 端口 D0~D3 | `UP_PORT` |

**推哪些帧由"回传内容"寄存器控制**（位掩码，见 §5.8）。

### 3.1 姿态角（ID 0x01，LEN = 6）

| 偏移 | 类型 | 含义 | 换算 |
|---:|---|---|---|
| 0-1 | int16 LE | Roll 横滚角 | `raw / 32768 × 180` ° |
| 2-3 | int16 LE | Pitch 俯仰角 | 同上 |
| 4-5 | int16 LE | Yaw 航向角 | 同上 |

### 3.2 四元数（ID 0x02，LEN = 8）

| 偏移 | 类型 | 换算 |
|---:|---|---|
| 0-1 / 2-3 / 4-5 / 6-7 | int16 LE ×4 | Q0 / Q1 / Q2 / Q3，各 `raw / 32768` |

### 3.3 加速度计 + 陀螺仪（ID 0x03，LEN = 12）

> ⚠️ **注意顺序：加速度在前，陀螺在后**（容易记反）

| 偏移 | 类型 | 含义 | 换算 |
|---:|---|---|---|
| 0-1 | int16 LE | Acc X 原始 | `raw / 32768 × ACC_FSR` g |
| 2-3 | int16 LE | Acc Y | 同上 |
| 4-5 | int16 LE | Acc Z | 同上 |
| 6-7 | int16 LE | Gyro X 原始 | `raw / 32768 × GYRO_FSR` dps |
| 8-9 | int16 LE | Gyro Y | 同上 |
| 10-11 | int16 LE | Gyro Z | 同上 |

**满量程表**（值由量程寄存器决定，见 §5.3 / §5.4）：

```python
GYRO_FSR_DPS = [250, 500, 1000, 2000]   # 索引 = 寄存器取值 0..3
ACC_FSR_G    = [2, 4, 8, 16]            # 索引 = 寄存器取值 0..3
```

> 上位机连上后会先读这两个寄存器，之后换算才准。
> 读不到时默认按 **1000dps / 2g** 处理。

### 3.4 磁力计（ID 0x04，LEN = 8）

| 偏移 | 类型 | 含义 | 换算 |
|---:|---|---|---|
| 0-1 | int16 LE | Mag X 原始 | 直接是原始值（量纲未标定）|
| 2-3 | int16 LE | Mag Y | 同上 |
| 4-5 | int16 LE | Mag Z | 同上 |
| 6-7 | int16 LE | 温度 | `raw / 100` ℃ |

### 3.5 气压计（ID 0x05，LEN = 10）

| 偏移 | 类型 | 含义 | 单位 |
|---:|---|---|---|
| 0-3 | **int32** LE | 气压 | Pa |
| 4-7 | **int32** LE | 海拔 | cm |
| 8-9 | int16 LE | 温度 | `raw / 100` ℃ |

> 模块直接给海拔，也可以自己用国际标准大气公式反算做交叉验证：
> `alt = 44330 × (1 − (P / 101325)^0.190295)` 米

### 3.6 端口（ID 0x06，LEN = 8）

| 偏移 | 类型 | 含义 |
|---:|---|---|
| 0-1 / 2-3 / 4-5 / 6-7 | uint16 LE ×4 | D0 / D1 / D2 / D3 |

D0~D3 可配置成模拟输入 / 数字输入 / 输出高低 / 输出 PWM（见 §5.9~§5.12）。

## 4. 指令格式（帧头高 = 0xAF）

### 4.1 读寄存器

```
[0x55] [0xAF] [ID | 0x80] [0x01] [0x00] [CHECKSUM]        共 6 字节
```

注意 **ID 要或上 `0x80`** 才表示"读"。

### 4.2 写寄存器

```
[0x55] [0xAF] [ID] [LEN] [DATA ...] [CHECKSUM]           共 5+LEN 字节
```

**ID 不加 0x80** 就是写。LEN 可以是 1 或 2。

**举例** —— 设置回传内容为"姿态角 + 加速度/陀螺 + 气压计"（掩码 `0x15`）：

```
55 AF 08 01 15 22
         │  │  └─ 校验和 = 55+AF+08+01+15 = 0x122 & 0xFF = 0x22
         │  └─ 数据 = 0x15
         └─ LEN = 1
```

## 5. 寄存器一览（应答帧 ID）

| ID | 名称 | R/W | 说明 |
|---:|---|:---:|---|
| `0x00` | 保存到 Flash | W | 把当前配置持久化，断电不丢 |
| `0x01` | 传感器校准 | W | 触发校准流程 |
| `0x02` | 校准状态 | R | 读取当前校准状态 |
| `0x03` | 陀螺仪量程 | R/W | 0=250 1=500 2=1000 3=2000 dps |
| `0x04` | 加速度计量程 | R/W | 0=2 1=4 2=8 3=16 g |
| `0x05` | 陀螺仪带宽 | R/W | |
| `0x06` | 加速度计带宽 | R/W | |
| `0x07` | 波特率 | R/W | 0..7 对应 §1 的 8 档 |
| `0x08` | 回传内容 | R/W | **位掩码**，见下 |
| `0x09` | 回传内容 2 | R/W | 保留 |
| `0x0A` | 回传速率 | R/W | 见下 |
| `0x0B` | 算法 | R/W | 0=9 轴 1=6 轴 |
| `0x0C` | 安装方向 | R/W | 0=水平 1=竖直 2=倒置 3=侧装 |
| `0x0D` | 陀螺仪自校准 | R/W | 开关 |
| `0x0E` | 气压计自校准 | R/W | 开关 |
| `0x0F` | LED | R/W | 0=打开 1=关闭 |
| `0x10`~`0x13` | 端口 D0~D3 模式 | R/W | 0=模拟入 1=数字入 2=输出高 3=输出低 4=输出PWM |
| `0x16` / `0x1A` | D1 / D3 PWM 脉宽 | R/W | 2 字节 |
| `0x1F` / `0x23` | D1 / D3 PWM 周期 | R/W | 2 字节 |
| `0x7F` | 恢复默认设置 | W | |

### 5.1 回传内容位掩码（寄存器 0x08）

**bit(n−1) 对应帧 ID n**：

| 位 | 帧 ID | 内容 |
|---:|---:|---|
| bit0 | 0x01 | 姿态角 |
| bit1 | 0x02 | 四元数 |
| bit2 | 0x03 | 加速度/陀螺 |
| bit3 | 0x04 | 磁力计 |
| bit4 | 0x05 | 气压计 |
| bit5 | 0x06 | 端口 |

例：只要姿态角 + 加速度/陀螺 → `0b00000101` = `0x05`。

### 5.2 回传速率取值（寄存器 0x0A）

索引 0..10 依次是：

```
0.2Hz  0.5Hz  1Hz  2Hz  5Hz  10Hz  20Hz  50Hz  100Hz  200Hz  500Hz
```

> 举例里"100Hz"对应索引 **8**。启用多种帧时，实际带宽是各帧速率之和，
> 波特率不够会导致丢帧 —— 高回传速率建议同时提高波特率。

## 6. 上位机能做什么

[`tools/imu_gui.py`](tools/imu_gui.py) 已覆盖全部上述功能：

| 页签 | 功能 |
|---|---|
| **姿态** | 人工地平仪（Roll/Pitch）+ 罗盘（Yaw）+ 全部数值 |
| **波形** | 加速度 / 陀螺 / 磁力 三轴实时曲线，自动量程 |
| **配置** | 波特率、回传速率、量程、算法、安装方向、LED、回传内容勾选、通用寄存器读写、校准/保存/恢复 |
| **数据** | CSV 记录（20 列全量）+ 原始帧监视（看模块实际发了什么）|

```bash
/usr/bin/python3 tools/imu_gui.py
```

> 用系统自带的 `/usr/bin/python3`（有 tkinter + pyserial）。
> 画面全部用 tkinter Canvas 手绘，**不需要 matplotlib / numpy**。

## 7. 排查

| 现象 | 可能原因 |
|---|---|
| 完全收不到帧 | TX/RX 没交叉；波特率不对；没共地 |
| 帧率很低 | 回传速率设太低，或回传内容勾了太多帧超出带宽 |
| 数值跳变/丢帧 | 波特率不够（高回传速率 + 多种帧）|
| 角度漂移 | 没做校准；或用了 6 轴算法（无磁力修正，偏航会缓慢漂）|
| 加速度单位不对 | 量程寄存器没读到，用了默认 2g（连上后会自己读一次）|
| 收到帧但校验失败 | 线太长/干扰；缩短杜邦线，或降波特率 |
