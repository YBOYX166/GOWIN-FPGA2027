# Gpio1 整组固定 PWM 测试固件

目的：**完全绕开电机链路**，直接确认 P2 排针（Gpio1[35:0]，全 36 根）到底有没有输出。

## 改动内容

`src/top.v` 新增调试开关（第 259~278 行）：

```verilog
localparam Gpio1AllPwm    = 1;
localparam GPIO1_PWM_HZ   = 20_000;  // 改成 2 就是 2Hz
localparam GPIO1_PWM_DUTY = 50;
```

`Gpio1AllPwm = 1` 时：

```verilog
gpio1_oe  = {36{1'b1}};
gpio1_out = {36{gpio1_test_pwm}};
```

- **Gpio1[35:0] 全部 36 根**输出同一个固定 PWM（已从网表确认：28 个 TBUF + 8 个 IOBUF，
  驱动源全为 `gpio1_test_pwm`，`OEN` 全为 `GND` 即使能）。
- **Gpio0 完全没动**，屏照常显示（只有 R5 = Gpio1[28] 被测试 PWM 取代，
  红色最低位变成 50% 常亮，画面仍清晰可辨，可继续当作"FPGA 活着"的指示）。
- 电机链路因输出未被引用而被综合优化掉，所以**这次时序是干净的**
  （clk50 实测 Fmax 122 MHz，setup 失败端点 0）。

## 两个固件

| 文件 | 频率 | 占空比 | 用途 |
| --- | --- | --- | --- |
| `gpio1_pwm_20kHz.fs` | 20 kHz | 50 % | 与电机 PWM 同频，最贴近真实工况 |
| `gpio1_pwm_2Hz.fs` | 2 Hz | 50 % | **任何示波器时基都能看出的慢方波**，用于排除时基问题 |

2 Hz 版本是专门给你的：周期 0.5 s，示波器哪怕在 100 ms/div 也能看到干净方波；
万用表直流档会看到读数在 0 V / 3.3 V 之间每秒跳变。

## 烧录

Gowin Programmer → 选 `GW5AT-138C` → 加载对应 `.fs` → Program。

## 测量点

P2 排针**任意一根**都应该是同一个 PWM（因为全组都在输出）。建议先用
**P2-1（F13）**，再用 **P2-33（D20）** 交叉确认（33 脚远离电机区）。

| 固件 | 万用表 DC | 万用表 Hz 档 | 示波器 |
| --- | --- | --- | --- |
| 20 kHz | ≈1.65 V | ≈20.00 kHz | 时基 ≤10 µs/div 见方波 |
| 2 Hz | 0 V / 3.3 V 每秒跳变 | — | 100 ms/div 即可见方波 |

## 注意

- 此模式下 `Gpio1[21:14]`（编码器输入）变成输出，**若编码器已接线请先断开**，避免两边对驱。
- 恢复电机功能：把 `src/top.v` 里 `Gpio1AllPwm` 改回 `0` 重新编译即可。
