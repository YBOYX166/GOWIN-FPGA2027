| 13 | [10] | IN1_3 | 片1 **BIN1** | 3.3V |

> ⚠️ **P2-11 = 5V、P2-12 = GND**（原理图 VCC5P0 / GND），是电源脚，**绝对不能接信号线**。
> 所以"方向线"在物理上不连续：**P2-5~10 + P2-13~14**。
>
> ⚠️ 一个模块的 4 根方向线**挨在一起**（P2-5~8 是片0，P2-9/10/13/14 是片1），
> 不要按"4 根 IN1 排一起、4 根 IN2 排一起"来接。

网表实测确认：

```
轮0: Gpio1[15:14] -> P2-17/18  -> mt_speed[15:0]
轮1: Gpio1[17:16] -> P2-19/20  -> mt_speed[31:16]
```

## 串口输出

每 200ms 一行（115200 / 8 / N / 1）：

```
S0=+02200 S1=+02195 S2=-00004 S3=+02210
```

单位 = **计数/秒**（counts per second，带符号）—— **M/T 法**测速的输出。
每路 5 位数，范围 ±32767。

```
RPM = cps × 60 / CPR
cps = RPM × CPR / 60
```

CPR=1320 时：**RPM = cps × 0.04545**，反之 **cps = RPM × 22**

| cps | 转速 |
| ---: | ---: |
| 220 | 10 RPM |
| 1100 | 50 RPM |
| 2200 | 100 RPM |
| 11000 | 500 RPM |

### 测速性能

| 项 | 值 |
| --- | --- |
| 方法 | M/T（数脉冲 + 实测脉冲间隔时间） |
| 刷新率 | 100 Hz（每 10ms 一个读数） |
| 分辨率 | ≈1 cps ≈ 0.045 RPM |
| **可测下限** | **≈0.3 RPM**（边沿间隔需 < 150ms 的停转判据） |
| 停转判定 | 连续 150ms 无编码器边沿 -> 输出 0 |
| 低速保持 | 某闸门内无边沿时保持上次速度，读数不抖 |

## 源码开关（`src/top.v`）

```verilog
localparam MOTOR_IFACE = 1;   // 1 = TB6612/DRV8833   0 = AT8236
localparam GPIO1_MODE  = 3;   // 0=真驱动 1=4路PWM验证 2=全组 3=转轮自检
localparam DEMO_V      = 700; // 真驱动模式下的速度，占空比 = DEMO_V/1000
localparam DEMO_MODE   = 1;   // 1=固定指令  0=8相位演示序列
```

`motor_quad` 实例里 `.CLOSED_LOOP (0)` = 开环；改 1 接上编码器即闭环。
